# Zoo Simulator

A 3D zoological park simulation built on the CNA ecosystem (CNA, Sharp Runtime, CNA Engine):
build habitats, care for animals with believable needs and behaviour, welcome visitors, hire
staff and keep the zoo financially alive.

The project is under active development. What is implemented, what is verified and what is
missing is tracked honestly in [`docs/STATUS.md`](docs/STATUS.md).

## Building (Linux)

The CNA libraries are expected as sibling checkouts (see `docs/DEPENDENCIES.md`); the default
layout is

```
github.com/libcna/{cna,sharp-runtime,cna-engine,easy-gl,meta-gl,...}
github.com/openeggbert/zoo-simulator        <- this repository
```

Another location is given with `-DZOO_LIBCNA_ROOT=/path/to/libcna`.

```bash
cmake -S . -B build -G Ninja \
      -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DCMAKE_C_COMPILER_LAUNCHER=ccache
cmake --build build --parallel 6
ctest --test-dir build --output-on-failure
cd build && ./zoo-simulator
```

## Layout

| Path | Contents |
|---|---|
| `src/core/` | `zoo_core`: the simulation (world, construction, animals, visitors, staff, economy, persistence). No dependency on CNA; deterministic; unit tested. |
| `src/game/` | The CNA / CNA Engine application: rendering, cameras, input, UI, audio. |
| `data/` | Data-driven definitions (species, buildings, items, scenarios) as JSON. |
| `assets/` | Runtime assets. Animal models are generated by `tools/animals`. |
| `tools/animals/` | `zoogen`: the reproducible procedural animal pipeline (Blender, headless). |
| `tests/` | GoogleTest suites for `zoo_core` and tool tests. |
| `docs/` | Architecture, roadmap, status, asset pipeline, testing, performance. |
