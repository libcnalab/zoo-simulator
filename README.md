# Zoo Simulator

A first-person walk through a zoological garden, built on the CNA ecosystem (CNA, Sharp Runtime,
CNA Engine). You are a **visitor**: the game opens at the gate of a finished,
populated zoo and you walk it at eye level — habitats with animals that eat, drink, rest, play
and call, other visitors strolling, watching and sitting on benches, food courts, information
boards, the sound of the park around you.

It began as a zoo-building game and changed direction on 2026-11-12;
[`docs/PIVOT_TO_ZOO_EXPLORATION.md`](docs/PIVOT_TO_ZOO_EXPLORATION.md) says what changed, what was
verified and what is not good enough yet. The animals are stylised procedural models, not
photorealistic ones.

## Playing

```bash
cd build && ./zoo-simulator
```

*Visit Zoo* on the title starts a morning at Greenhill Zoo (see
[`docs/VISITOR_ZOO.md`](docs/VISITOR_ZOO.md) for its plan).

| Key | |
|---|---|
| `W A S D`, arrows | walk |
| Mouse | look around |
| `Shift` | switch between walking and running (press once; it stays) |
| `E` | read the information board you stand at |
| `M` | visitor map |
| `Esc` | pause menu (resume, save, load, settings); releases the mouse |
| `F5` | save the visit |
| `F4` | diagnostics (visitors, avatars, sound) |

Looking at an animal shows its name, species and what it is doing.

`./zoo-simulator --editor` starts the former management game (build, finances, overview camera).
It is kept working but is not the game. `./zoo-simulator --viewer --animal lion` shows one animal
model and its clips.

## Building (Linux)

The CNA libraries are expected as sibling checkouts; the default layout is

```
github.com/libcna/{cna,sharp-runtime,cna-engine,easy-gl,meta-gl,...}
github.com/openeggbert/zoo-simulator        <- this repository
```

Another location is given with `-DZOO_LIBCNA_ROOT=/path/to/libcna`.

```bash
cmake -S . -B build -G Ninja \
      -DCMAKE_CXX_COMPILER_LAUNCHER=ccache -DCMAKE_C_COMPILER_LAUNCHER=ccache
cmake --build build --parallel 4
ctest --test-dir build --output-on-failure
```

Sanitizer builds of the simulation core: add `-DZOO_SANITIZE=address -DZOO_BUILD_GAME=OFF` and
build in `build-asan/`.

## Layout

| Path | Contents |
|---|---|
| `src/core/` | `zoo_core`: the simulation (world, construction, animals, visitors, the Visitor Zoo scenario, persistence). No dependency on CNA; deterministic; unit tested. |
| `src/game/` | The CNA / CNA Engine application: the visit (walker, title, pause, map, boards), rendering of terrain, scenery, animals and avatar visitors, sound, and the editor. |
| `data/` | Data-driven definitions (species, fences, buildings, props) as JSON. |
| `assets/animals/` | Animal models, generated by `tools/animals`. |
| `assets/audio/` | Recordings; every file's source and licence is in `assets/audio/SOURCES.md`. |
| `tools/animals/` | `zoogen`: the reproducible procedural animal pipeline (Blender, headless). |
| `tests/` | GoogleTest suites for `zoo_core`. |
| `docs/` | The pivot, the zoo's plan, animals and their behaviour, visitors, construction, the log of delegated tasks. |
