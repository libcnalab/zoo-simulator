# Animals

## Species data

Each species is defined by one JSON file in `data/species/`. Biological values use real-world units; prices and appeal are game values. Minimum enclosure area is scaled to roughly half of common husbandry recommendations for the smallest proper group, and additional-animal space is scaled in proportion. Prices and appeal share one game-wide scale, from inexpensive small species to large, rare, or especially popular animals.

## Models

Every species has a model in `assets/animals/<id>.glb` with a description beside it
(`<id>.json`: clips, their lengths, ground speeds and step events). They are generated by
`tools/animals` (`zoogen`, Blender 4.3 run headless) from one species file each in
`tools/animals/species/`, so a model is rebuilt, not edited:

```bash
blender -b --factory-startup --python tools/animals/build_animal.py -- \
    --species lion --out assets/animals --preview build-probe/animal-previews
python3 -m unittest discover -s tools/animals/tests
```

| Generator | Species |
|---|---|
| `zoogen/quadruped.py`, `wild_quadruped.py`, `anatomy.py` | lion, tiger, wolf, brown bear, polar bear, zebra, giraffe, elephant, rhino, camel, meerkat |
| `zoogen/biped.py` | penguin, ostrich, flamingo, kangaroo |

Each has the same eight clips, which the game picks from what the animal is doing: `idle`,
`walk`, `trot` (the fast gait, a hop for the kangaroo), `eat`, `drink`, `rest`, `sleep`,
`vocalize`. 9,000 to 21,000 triangles, 18 to 41 bones, a coat painted by the species file. The models are stylised, not photorealistic; what each is weak at is listed in
[`PIVOT_TO_ZOO_EXPLORATION.md`](PIVOT_TO_ZOO_EXPLORATION.md).

A species without a model would be left out of the Visitor Zoo by the game (its habitat built
and standing empty).
